# Риски, комплаенс и границы продукта

Источник: агенты ресерча `anticheat_safety`, `tweaks_efficacy`, `exmtweaks_teardown`, `saas_pricing`.
Машинная версия: `data/product_rules.json`.

## Главный вывод

ГЛАВНЫЙ ВЫВОД: ни один из пяти мейджорных античитов (EAC, Vanguard, VAC, BattlEye, RICOCHET, +EA Javelin) НЕ БАНИТ за твики Windows, реестр, службы, конфиги и оверлеи. Все вендоры официально заявляют, что бан выдаётся только за читы/тамперинг игры. Реальный риск проекта — НЕ баны, а ЖЁСТКАЯ БЛОКИРОВКА ЗАПУСКА ИГРЫ: в 2025-2026 античиты массово перешли на требование аппаратных security-фич, которые классические "FPS-твикеры" как раз отключают. Конкретно: Valorant/Vanguard на Win11 требует TPM 2.0 + UEFI Secure Boot (офиц. мин. спеки, 16.09.2025), а при VAN: RESTRICTION дополнительно IOMMU и HVCI/VBS Memory Integrity (Core Isolation) + VAN 9002 требует, чтобы ВСЕ Windows Exploit Protection мitigations (DEP/CFG/ASLR/SEHOP/heap integrity) стояли на "Use default"; Fortnite с 19.02.2026 требует Secure Boot + TPM + IOMMU для ВСЕХ турниров; Call of Duty требует TPM 2.0 + Secure Boot с аттестацией через Microsoft Azure Attestation, обязательно для Black Ops 7; EA Javelin (Battlefield 6, FC) требует Secure Boot и имеет ПУБЛИЧНЫЙ denylist драйверов (~30 позиций: WinRing0, HWiNFO, CPU-Z, Core Temp, Process Explorer, Razer Synapse, MSI ntiolib/winio, reWASD, Daemon Tools, Voicemod). Второй критический вывод: ПРОДУКТ НЕ ДОЛЖЕН СОДЕРЖАТЬ СВОЙ KERNEL-ДРАЙВЕР И НЕ ДОЛЖЕН ТЯНУТЬ СТОРОННИЕ ИНСТРУМЕНТЫ С ДРАЙВЕРАМИ — с Windows 11 2022 Update Microsoft-блоклист уязвимых драйверов включён по умолчанию и принудительно применяется при HVCI, а EAC/BattlEye/Javelin отдельно блокируют такие драйверы. Третий: твики, ломающие measured boot / bootlog / PCR (bcdedit-хаки, кастомные загрузчики, test-signing, отключение driver signature enforcement, kernel debugging, Driver Verifier), дают жёсткие ошибки EAC/BattlEye. Безопасный периметр продукта — 100% user-mode: планы электропитания, настройки драйвера GPU, внутриигровые настройки и конфиги через легальные средства игры, отключение фонового софта, обновление драйверов (Valve прямо называет это НЕ причиной бана).

## Правила, которые продукт обязан соблюдать

- HARD_DENY_LIST (скрипт продукта НИКОГДА не выполняет, без опции и без 'advanced mode'): отключение Secure Boot; отключение/очистка TPM; переключение UEFI→Legacy/CSM; отключение IOMMU / Intel VT-d / AMD-Vi / DMA Protection / DMAr; bcdedit /set testsigning on; bcdedit /set nointegritychecks on; bcdedit /set debug on; отключение driver signature enforcement; включение Driver Verifier; любые правки BCD, затрагивающие measured boot; отключение UAC (EnableLUA=0); отключение Windows Defender; отключение Windows Exploit Protection mitigations (DEP/CFG/ASLR/SEHOP/heap integrity) системно или per-process; bcdedit /set nx AlwaysOff; правка MitigationOptions в Session Manager\Kernel
- CONDITIONAL_RULE_VBS (единственная ветвящаяся константа): if (Windows 11) OR (Windows 10 AND BIOSMode==UEFI AND TPM==2.0) → VBS/HVCI/Core Isolation НЕ ТРОГАТЬ (иначе VAN: RESTRICTION в Valorant/LoL); elif (Windows 10 AND (no UEFI OR no TPM 2.0)) → отключение VBS допустимо (сам Riot это предписывает при VAN 9005). Реализовать как detect-then-branch, не как глобальный тумблер
- PROTECTED_SERVICES_WHITELIST (скрипт не останавливает/не отключает/не удаляет ни в каком режиме): vgc, vgk, EasyAntiCheat, EasyAntiCheat_EOS, BEService, BEDaisy, EAAntiCheat, EAAntiCheat.GameServiceLauncher, Ricochet/CODAntiCheat, Hyperion/RobloxPlayerBeta, а также Windows-компоненты: WinDefend, SecurityHealthService, TrustedInstaller, tbs (TPM Base Services), Measured Boot / Microsoft-Windows-Kernel-Boot ETW
- GAME_FILES_RULE: скрипт не изменяет ни один файл в каталоге установки игры. Разрешено писать только в пользовательские конфиги вне каталога игры (Documents\My Games\..., %LOCALAPPDATA%\<Game>\Saved\Config\). Запрещено: d3d9.dll/dxgi.dll/winmm.dll-прокси, DLL-инжект, ReShade в Fortnite и PUBG, правка pak/vpk
- THIRD_PARTY_DENY_LIST (не бандлить, не устанавливать, не рекомендовать в гайдах; детектить и выводить предупреждение — источник: публичный denylist EA Javelin + BattlEye FAQ): CPU-Z, Core Temp, HWiNFO, Process Explorer, EVGA Precision XOC/X1 LED Sync (WinRing0), MSI Command Center / Super Charger / Gaming App / Creator Center / Dragon Center, GIGABYTE Aorus Engine / OC Guru II / Xtreme Engine / RGB Fusion, ASRock RGBLED / A-Tuning, IObit Advanced SystemCare, Razer Synapse, Samsung Magician, Trident Z Lighting Control, Voicemod, SpeedFan, Daemon Tools, reWASD
- MONITORING_ARCH_RULE: мониторинг FPS/температур только user-mode через Windows API / WMI / PDH / PresentMon или встроенные оверлеи самих игр. Запрещены любые зависимости от kernel-драйверов (WinRing0, inpoutx64, ntiolib, winio, alsysio, glckio, atillk, gpcidrv, asrdrv, eneio, msio, hwinfo64a, procexp*)
- PRODUCT_ARCH_CONSTANT: продукт не содержит и не устанавливает собственный kernel-драйвер (.sys) ни в каком виде. Обоснование: Microsoft blocklist принудителен при HVCI по умолчанию на Win11 + EAC/BattlEye/Javelin отдельно блокируют драйверы + Riot прямо пишет про непредсказуемые взаимодействия с драйвером Vanguard
- PREFLIGHT_CHECK (обязательный модуль перед применением и перед запуском игры, все проверки read-only): msinfo32-эквивалент → BIOS Mode (ожидание UEFI), Secure Boot State (On); tpmtool getdeviceinformation → TPM Present=true, Version=2.0, Is Initialized=true, Ready For Attestation=true; get-tpm → TpmPresent/TpmReady/TpmEnabled/TpmOwned/AutoProvisioning=true; VBS state; Memory Integrity state; IOMMU/VT-d state; наличие secnvme.sys/solidnvm.sys/asstahci64.sys; наличие AppCompatFlags\Layers для exe античит-игр; наличие процессов из THIRD_PARTY_DENY_LIST
- PER_GAME_PROFILE_MATRIX (обязательная структура данных, не единый профиль): Valorant/LoL → keep TPM+SecureBoot+IOMMU+HVCI+ExploitProtection default, no VM, no compatibility mode, no OC на 13/14 gen; Fortnite → keep SecureBoot+TPM+IOMMU, no ReShade, выгружать оверлеи; Rust/PUBG/Tarkov/DayZ (BattlEye) → Low Latency Mode ≠ Ultra, no macro tools, no ReShade в PUBG; CS2 → cl_allow_multi_input_binds остаётся 0, no null-binds, no exec_async-трюки; CoD → keep TPM+SecureBoot, Win10 22H2+, не трогать TPM/PCR; Battlefield 6/FC/Apex (Javelin) → keep Defender + SecureBoot, denylist-детект, только одобренные ремапперы; Roblox → keep UAC+TPM+SecureBoot
- OVERLAY_UNLOAD_RULE: лаунчер продукта обязан иметь режим 'полная выгрузка перед запуском античит-игры' (никаких оверлеев, хуков, hotkey-хуков, мониторинга) — прямо соответствует рекомендации EAC ('temporarily close the conflicting software before launching the game') и Riot VAN 9101 ('remove any third-party software… even if it's related to other games')
- FORBIDDEN_PRODUCT_FEATURES (иначе продукт классифицируется как cheat/ban-evasion tool → блокировка Stripe/PayPal и юридический риск): смена/спуфинг HWID, обход HWID-бана, unban-сервисы, макросы/anti-recoil, ремапперы типа reWASD, SOCD/null-cancel, FOV/zoom-моды, любые чтения/записи памяти игры, DLL-инжект, отключение античита
- DISCLAIMER_TEXT_CONSTANTS (для карточки товара, Discord-правил и обязательного чекбокса при оплате; каждый пункт подкреплён цитируемым официальным источником): (1) 'Our tweaks are user-mode only. We do not install kernel drivers, do not modify game files, and do not interact with any anti-cheat.' (2) 'We never disable Secure Boot, TPM, IOMMU, Core Isolation or Windows Exploit Protection — these are required by Riot Vanguard, Easy Anti-Cheat, EA Javelin and Call of Duty.' (3) 'Anti-cheat vendors state they ban only for actual cheats — e.g. Valve: system hardware configurations and updated drivers do not trigger a VAC ban; BattlEye: we only ever ban for the use of actual cheats/hacks; Easy Anti-Cheat: blocking is not permanent.' (4) 'We cannot guarantee any outcome from a game publisher. Anti-cheat rules change (Fortnite added IOMMU on Feb 19, 2026; Call of Duty added TPM+Secure Boot in Aug 2025).' (5) 'Requirements: Windows 10 22H2 / Windows 11, UEFI + GPT, Secure Boot and TPM 2.0 enabled. Virtual machines and cloud gaming are not supported by Valorant.' (6) 'We do not sell cheats, macros, HWID spoofers, unban services or account services.'
- AUTO_UPLOAD_CONTENT_RULES (жёсткие фильтры для авто-генерации текстов/озвучки/титров коротких видео — нарушение этих правил создаёт юридический и платёжный риск и повод для страйков): BANNED_PHRASES = ['undetected','bypass anticheat','anticheat bypass','ban-proof','100% ban safe','no ban guarantee','HWID spoof','unban','disable Secure Boot','disable TPM','disable Core Isolation','disable Defender','disable VBS','turn off anticheat','aim assist','no recoil','macro']; REQUIRED_OVERLAY на каждом видео = 'Tweaks only. No cheats. No kernel driver.'; REQUIRED_DESCRIPTION_LINE = ссылка на дисклеймер + 'Requires Secure Boot + TPM 2.0 enabled'; CLAIM_CAP = FPS-прирост указывать только диапазоном с указанием конфигурации и пометкой 'results vary', без абсолютных обещаний
- SUPPORT_BOT_KB_CONSTANT: зашить таблицу кодов ошибок как справочник 'блок vs бан': VAN 9001/9002/9003/9004/9005/9006/RESTRICTION/9101/138 = БЛОК (устранимо), VAN 61/152 = БАН (не устранимо); BattlEye 'Blocked loading of file' = не бан; EAC 'blocked software' = не бан, 'Unknown file version' = проверить файлы; Javelin 'incompatible software/driver' = не бан, закрыть/обновить софт; VAC = бан, не апеллируется

## Карта рисков

- ГЛАВНЫЙ БИЗНЕС-РИСК — НЕ БАНЫ, А БЛОКИРОВКА ЗАПУСКА: если продукт отключает Secure Boot/TPM/IOMMU/Core Isolation/Exploit Protection/Defender/UAC, клиент физически не сможет запустить Valorant, LoL, Black Ops 7, Battlefield 6, Roblox, турниры Fortnite. Это даёт вал возвратов, чарджбэков и отзывов 'сломало игру' — при отсутствии формального нарушения правил площадок. Вероятность: высокая при использовании стандартных шаблонов FPS-твиков
- Конфликт требований между античитами делает единый глобальный профиль невозможным: BattlEye просит временно ОТКЛЮЧИТЬ Hardware-enforced Stack Protection (Core Isolation) для загрузки своего драйвера, а Vanguard при VAN: RESTRICTION ТРЕБУЕТ HVCI включённым. Аналогично VBS: Riot требует включённым на Win11 и предписывает отключить на Win10 без UEFI/TPM. Единый 'one-click optimize' гарантированно кого-то сломает
- Требования меняются без предупреждения и только в сторону ужесточения: Fortnite добавил IOMMU для всех турниров 19.02.2026; CoD добавил TPM+Secure Boot в августе 2025 и сделал обязательным для BO7. Любой профиль твиков устаревает — нужен онлайн-обновляемый набор правил, иначе продукт превратится в источник блокировок
- Любой kernel-драйвер в продукте = экзистенциальный риск: попадание в Microsoft vulnerable driver blocklist (включён по умолчанию на Win11, обновляется квартально) или в denylist EA Javelin / EAC / BattlEye делает продукт нерабочим у всей базы одновременно и навсегда закрепляет репутацию 'банит'. Плюс Microsoft прямо предупреждает о BSOD
- Ассортиментный риск: IObit Advanced SystemCare — прямой аналог 'PC оптимизатора' — находится в ПУБЛИЧНОМ denylist EA Javelin (monitor_win10_x64.sys). Это прецедент: класс 'оптимизаторов с драйвером' уже в чёрных списках. Если продукт пойдёт этим путём, попадание в denylist — вопрос времени
- Платёжный/юридический риск при дрейфе продукта в серую зону: HWID-спуфинг, unban-сервисы, макросы, anti-recoil, ремапперы класса reWASD, продажа аккаунтов. Epic в 2025-2026 системно судится (решение на $175 000, иски к продавцам читов и аккаунтов, пожизненные баны), Riot снимает ранговые награды. Stripe/PayPal закрывают такие мерчанты. Риск: критический, если апселл уйдёт в 'игровые аккаунты'
- Риск ложных срабатываний вне контроля оператора: Valve дважды за 8 месяцев (12.2025, 01.2026) выдавала ошибочные VAC-баны. Клиенты будут приписывать это продукту. Нужны публичные доказательства отсутствия драйвера/инжекта (open-source манифест изменений, хеши, changelog реестровых правок) — иначе репутация не защищается
- Аппаратный риск: любой 'CPU boost'/повышение power limits на Intel 13/14 gen ведёт к BSOD vgk.sys в Riot-играх — Riot официально предписывает ОТКЛЮЧАТЬ оверклок и снижать множители. Продукт, повышающий частоты/PL, будет ломать ПК клиентов с деградировавшими CPU
- Риск для CS2-контента: null-bind/null-cancel конфиги и SOCD дают КИК из матчей на официальных серверах (Valve, 19.08.2024) и мульти-бинды игнорируются по умолчанию. Продажа таких 'про-конфигов' = гарантированные жалобы, даже без бана
- Репутационный риск от копирования маркетинга debloat-проектов: заявление типа 'поддерживаем все античиты' (AtlasOS) опровергается их же FAQ (FIFA/EAFC требуют Defender, Roblox требует UAC+TPM+Secure Boot). Копирование такой формулировки = прямой повод для возвратов и обвинений в обмане
- Support-нагрузка на одного оператора: 9 разных античитов × индивидуальные VAN/EAC/BE/Javelin коды ошибок + требования BIOS (TPM/Secure Boot/IOMMU/MBR→GPT) = тикеты, требующие BIOS-консультаций. Риск: без предзашитого KB и пре-флайт-чека один человек не справится, особенно с аудиторией 13-24 лет на ноутбуках
- Юридический риск инструкций по BIOS: Riot и EA в своих же статьях снимают ответственность ('EA doesn't take responsibility for changes to your BIOS settings', 'Riot is not responsible for any issues that may result from modifying your BIOS'). Продукт, инструктирующий менять BIOS или конвертировать MBR→GPT, несёт риск 'вы убили мой ПК' — нужен аналогичный дисклеймер и отказ от автоматизации BIOS/диска

## Что из твиков реально работает

Реальная эффективность "твиков" распадается на три группы. (1) ЧЕСТНО РАБОТАЕТ И ИЗМЕРЕНО: NVIDIA Reflex/Reflex 2 (проверено LDAT-замерами TFTCentral: −5 ms на 60 Hz, −1..2 ms на 240-360 Hz; вендорские данные NVIDIA: Fortnite 56→38 ms на GTX 1660 Super 1080p/60 Hz = −33%; Reflex 2 Frame Warp в THE FINALS 56→27→14 ms на RTX 5070), Game Mode + разгрузка фона (замер MakeUseOf 07.2026 на i7-13700H/RTX 4060 Laptop: средний FPS +0.4..1.6%, но 1% low CS2 142.3→154.6 = +8.6%, Forza Horizon 5 с открытыми Edge+Discord 48.2→71.5 = +48%), XMP/EXPO и апскейлеры (DLSS/FSR) в CPU-bound сценах, CPU undervolt+boost override (igor'sLAB 11.2024, 9800X3D: +12.5% @720p, +8.4% @1080p, +6.3% @1440p, при СНИЖЕНИИ потребления), отключение VBS/Memory Integrity (Microsoft официально признаёт бОльший удар по производительности на CPU без MBEC/GMET, т.е. Intel до Kaby Lake и AMD до Zen 2). (2) ШУМ ±0-3%: HAGS (Microsoft: "users shouldn't notice any major differences in-game"), ReBAR на NVIDIA в среднем, план питания, большинство "debloat"-скриптов. (3) ЧИСТЫЙ СНЕЙК-ОЙЛ: чистка реестра (Malwarebytes: "digital snake oil", Microsoft официально не поддерживает registry cleaners), RAM-бустеры, дефрагментация SSD, "сетевые твики для снижения пинга" (пинг = физика маршрута, реестром не меняется). ОТДЕЛЬНО критично: DLSS 5 (neural rendering) — НЕ ускоритель: Digital Foundry через XDA 11.09.2026, NBA 2K27 4K на RTX 5090: 128.4 → 62.7 FPS = −51.2%. Обещать "x2 FPS" нельзя. Главный риск проекта — технически грамотная аудитория (r/nvidia, r/pcmasterrace, Blur Busters) разносит проекты за завышенные цифры; защита от возвратов = протокол измерения до/после (CapFrameX/PresentMon/FrameView, 3 прогона одной сцены) в оффере, а не громкие цифры. ВАЖНО: в этой сессии бюджет WebSearch был исчерпан (200/200) внешними вызовами, а techspot/techpowerup/blurbusters/neogaf/web.archive отдали 403 — часть пунктов (ReBAR по играм, XMP-проценты, стоимость оверлеев в FPS, эффект отката драйвера, per-game настройки Fortnite/Valorant/CS2/Rust/DBD) НЕ подтверждена первичным замером и помечена low/medium confidence. Их надо доверифицировать перед публикацией цифр.

- CPU OC+UV (9800X3D + RTX 4090, Curve Optimizer + 200 MHz): +12.5% @720p, +8.4% @1080p, +6.3% @1440p; 1% low +11-12% @1080p; потребление НЕ выросло
