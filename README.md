# GameTweaks Traffic Engine

Проект: SaaS-подписка на твики/оптимизацию ПК для геймеров (позиционирование UK/EN) + сопутствующие
товары (мини-ПК, ноутбуки, кастомные коврики). Канал привлечения — массовый авто-залив коротких
вертикальных видео в TikTok / YouTube Shorts / Instagram Reels по нескольким гео.

Этот репозиторий — **не маркетинговая методичка для чтения**, а спецификация + данные + код,
по которым LLM-агент (или человек) собирает и эксплуатирует систему авто-залива.

## Как этим пользоваться

| Что нужно | Куда идти |

| Понять стратегию по гео | `docs/02-geo-playbooks.md` + `data/geos.json` |
| Разложить 20 каналов на гео | `docs/03-channel-network.md` + `data/channels.json` |

| Не попасть под баны и чарджбеки | `docs/06-risks-compliance.md` + `data/product_rules.json` |
| Выбрать платёжный рельс (решается ДО всего остального) | `data/payments.json` + `docs/05-funnel-monetization.md` |

## Принципы, на которых построена система

1. **Данные отдельно от кода.** Все гео, тайминги, хуки, цены, лимиты — в `data/*.json`.
   Меняется стратегия — меняется JSON, код не трогается.
2. **Публикация через официальные API там, где она официально возможна.** Всё, что требует
   ручного шага, система готовит в виде очереди задач для человека, а не притворяется, что
   сделала (см. `SPEC.md`, раздел «Модель публикации»).
3. **Каждое видео уникально на уровне рендера.** Не «один файл в 20 аккаунтов», а генерация
   вариантов из ассетов: разный монтаж, тексты, аудио, тайминги, кадрирование.
4. **Атрибуция с первого дня.** Каждый канал = своя ссылка/инвайт/промокод, иначе решения
   принимаются на ощупь.
5. **Гео решается языком и контентом, а не только IP.** См. `docs/01-strategy.md`.

## Пять выводов ресерча, которые меняют план

1. **Гео решается страной, а не городом.** Органической гео-выдачи мельче страны не
   существует ни на одной площадке: эксперимент с GPS-спуфингом в три штата США дал
   одинаковую выдачу. Подстрановой таргет (город, DMA, zip) есть только в платных
   кабинетах. Прокси нужен страново-корректный, и всё; «IP Нью-Йорка против
   Вашингтона» — трата денег.
2. **Платёжный рельс решается первым.** Stripe не работает ни в одной стране СНГ, а
   страна юрлица фиксируется навсегда при первом платеже. EXM Tweaks, прямой
   ориентир проекта, решил это словацким юрлицом. Paddle продукт такого класса
   запрещает дословно. И отдельно: Ирак и Россия — страны, которым платёжки не дают
   платить, так что лить туда показы бессмысленно.
3. **Главный риск продукта — не баны, а сломанный запуск игр.** Античиты не банят за
   твики, но требуют Secure Boot, TPM и IOMMU — то, что твикеры отключают. Продукт,
   выключивший их, лишает клиента возможности запустить Valorant, Black Ops 7,
   Battlefield 6 и турниры Fortnite. Это возвраты и потеря платёжки.

4. **Локальный метод оплаты не равно подписка.** BLIK в Польше, MB WAY в Португалии
   и IRIS в Греции объявлены схемами обязательными — но у Stripe BLIK и MB WAY не
   поддерживают рекуррент, а IRIS не существует как метод и доступен только
   греческим юрлицам. Из локальных методов западного блока подписку реально тянет
   один iDEAL. Это не деталь интеграции: это решение, продаёте вы в гео подписку
   или lifetime.
5. **Австралия вышла из расчёта ядра.** Запрет соцсетей для детей до 16 действует с
   10.12.2025 и покрывает десять площадок сразу, включая YouTube и Twitch; штраф до
   A$49.5 млн, >200 тыс. TikTok-аккаунтов деактивировано в первую неделю. Нижняя
   половина целевого возраста там отсутствует не «частично», а полностью.
