# GameTweaks Traffic Engine

Проект: SaaS-подписка на твики/оптимизацию ПК для геймеров (позиционирование UK/EN) + сопутствующие
товары (мини-ПК, ноутбуки, кастомные коврики). Канал привлечения — массовый авто-залив коротких
вертикальных видео в TikTok / YouTube Shorts / Instagram Reels по нескольким гео.

Этот репозиторий — **не маркетинговая методичка для чтения**, а спецификация + данные + код,
по которым LLM-агент (или человек) собирает и эксплуатирует систему авто-залива.

## Как этим пользоваться

| Что нужно | Куда идти |
|---|---|
| Собрать систему с нуля силами Claude/GPT | `SPEC.md` — читается сверху вниз, это ТЗ |
| Понять стратегию по гео | `docs/02-geo-playbooks.md` + `data/geos.json` |
| Разложить 20 каналов на гео | `docs/03-channel-network.md` + `data/channels.json` |
| Взять идеи/хуки под видео | `docs/04-content-system.md` + `data/content_bank.json` |
| Настроить тайминги постинга | `data/schedule.json` |
| Узнать лимиты и квоты площадок | `data/platform_limits.json` |
| Не попасть под баны и чарджбеки | `docs/06-risks-compliance.md` |
| Эксплуатация: что делать каждый день | `ops/RUNBOOK.md` |

## Принципы, на которых построена система

1. **Данные отдельно от кода.** Все гео, тайминги, хуки, цены, лимиты — в `data/*.json`.
   Меняется стратегия — меняется JSON, код не трогается.
2. **Публикация через официальные API там, где она официально возможна.** Всё, что требует
   ручного шага, система готовит в виде очереди задач для человека, а не притворяется, что
   сделала (см. `SPEC.md`, раздел «Модель публикации»).
3. **Каждое видео уникально на уровне рендера.** Не «один файл в 20 аккаунтов», а генерация
   вариантов из ассетов: разный монтаж, тексты, аудио, тайминги, кадрирование.
4. **Атрибуция с первого дня.** Каждый канал = своя ссылка/инвайт/промокод, иначе решения
   принимаются на ощупь.
5. **Гео решается языком и контентом, а не только IP.** См. `docs/01-strategy.md`.
